Двенадцатая рабочая контрольная точка

Доведи экспорт до устойчивого инженерного состояния.

Собери строго это состояние:

каждый экспортированный .py файл синтаксически валиден

экспортированный код запускается без ручной правки

порядок генерации кода стабилен

special-container типы экспортируются без потери структуры

повторный экспорт одного и того же документа дает одинаковый результат

есть набор тестовых сценариев для быстрой проверки экспорта

зафиксирован окончательный шаблон экспортируемого Python-файла


Только после этого переходи к PythonImporter.


---

1. Цель двенадцатой контрольной точки

Закрой не только сам факт экспорта, а его надежность.

Нужно добиться, чтобы экспорт был:

предсказуемым

воспроизводимым

синтаксически чистым

пригодным для реального использования



---

2. Раздели проверку exporter на три уровня

Проверяй экспорт по трем независимым уровням:

Уровень 1. Синтаксис Python

Файл должен корректно парситься интерпретатором.

Уровень 2. Структура UI

Форма должна реально создаваться и показываться.

Уровень 3. Соответствие документу

Состав объектов, parent-child и свойства должны совпадать с FormDocument.


---

3. Добавь пост-экспортную синтаксическую проверку

Сделай отдельный модуль или helper для проверки экспортированного кода.

Создай, например:

conversion/export_validation.py

Создай класс:

ExportValidator



---

Реализуй методы

validate_python_syntax(code: str) -> None

validate_python_file(path: str) -> None



---

Реализация

Используй стандартный ast.parse(code).

Логика:

1. получить сгенерированный код как строку


2. прогнать через ast.parse


3. если есть ошибка:

не считать экспорт успешным

отдавать понятную ошибку с позицией





---

4. Встрой синтаксическую проверку в exporter

В PythonExporter.export_to_file(...) сделай:

1. сгенерировать код


2. проверить его синтаксис через ExportValidator


3. только потом писать файл на диск



Не записывай на диск заведомо битый код.

10. Проверь exporter на повторяемость

Сделай явный тест:

1. взять один и тот же FormDocument


2. экспортировать 2 раза


3. сравнить результат строка-в-строку



Результат должен совпадать полностью.

Если не совпадает:

у тебя есть нестабильный порядок генерации

исправляй порядок обхода детей и генерации внутренних ref

11. Стабилизируй обход children

Не полагайся на порядок в dict.

Категория B

Неверный порядок генерации

Категория C

Не применено свойство

Категория E

Категория F

Так проще вычищать exporter системно.
