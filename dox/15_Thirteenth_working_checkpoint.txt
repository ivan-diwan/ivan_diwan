Тринадцатая рабочая контрольная точка

Собери строго это состояние:

работает PythonImporter

импорт строится только как преобразование .py в нормализованный документ

восстанавливается FormRoot

восстанавливаются leaf-объекты

восстанавливаются обычные контейнеры

восстанавливаются:

QTabWidget

QScrollArea

QStackedWidget

QToolBox

QSplitter

QWizard


внутренние сущности (TabPage, ContainerContent, StackPage, ToolPage, SplitterPane, WizardPage) восстанавливаются обратно в документ

результат импорта пригоден для открытия в редакторе без ручной доработки

результат .py -> document -> export дает устойчивую обратную цепочку


После этого переходи к общей стабилизации и финальной фиксации конструктора.


---

1. Цель тринадцатой контрольной точки

Закрой обратное направление.

Пользователь должен мочь:

1. взять .py, экспортированный системой


2. загрузить его обратно


3. получить полноценный FormDocument


4. открыть форму в редакторе


5. продолжить редактирование


6. снова экспортировать без потери структуры




---

2. Зафиксируй границы importer

Импортер должен работать только на том подмножестве Python-кода, которое генерирует твой exporter.

Не пытайся делать универсальный анализ любого PySide6-кода.

Зафиксируй правило:

importer поддерживает только собственный экспортный формат

чужой свободный код PySide6 не считается обязательным сценарием



---

3. Построй importer через AST, а не через запуск кода

Не запускай импортируемый .py как живое приложение для извлечения структуры.

Строй importer через:

чтение файла

ast.parse(...)

анализ class/method/body

извлечение нормализованных операций



---

4. Создай модуль importer

Создай файл:

14. Восстанавливай QTabWidget

Лови структуру:

self.tab_widget_1 = QTabWidget(self)
self.tab_page_1 = QWidget()

self.tab_page_2 = QWidget()
self.tab_widget_1.addTab(self.tab_page_2, "Tab 2")
self.tab_widget_1.setCurrentIndex(0)


---

Алгоритм восстановления

1. зарегистрировать QTabWidget


2. зарегистрировать внутренние page widgets как TabPage


3. из addTab(page_ref, title):

установить у page:

parent_id = tab_widget_id

order

properties["title"]




4. из setCurrentIndex:

записать current_index





---

Правило

Не оставляй tab_page_1 как обычный QWidget документа.
Преобразуй его в внутреннюю сущность:

type = "TabPage"

23. Нормализуй name и id

Из Python ref:

self.push_button_1 восстанавливай:

name = "push_button_1"


id формируй либо:

таким же, как name или

через общий deterministic mapping


Для устойчивости importer/exporter цикла лучше:

id = name, если это имя уже уникально и соответствует модели

30. Зафиксируй ограничения importer

Импортер должен прямо считать ошибкой:

отсутствие root класса нужного шаблона

отсутствие setup_ui

отсутствие ожидаемых паттернов создания объектов

невозможность определить parent-child для special-container внутренней структуры


Не пытайся “угадывать” слишком много.
