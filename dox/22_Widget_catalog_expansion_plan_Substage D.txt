Подэтап D — QProgressBar

Подключай QProgressBar как отдельный leaf-объект полного цикла.
Закрой его полностью, прежде чем переходить к QTextEdit.


---

1. Цель подэтапа

Доведи QProgressBar до состояния, при котором он:

есть в палитре

создается на форме через drag&drop

выбирается

двигается

меняет размер

редактируется через PropertyPanel

сохраняется в JSON

экспортируется в .py

импортируется обратно

проходит round-trip без потери geometry и свойств



---

2. Зафиксируй модель QProgressBar

Считай QProgressBar обычным leaf-объектом.

Тип

7. Добавь QProgressBar в WidgetFactory

В factory/widget_factory.py добавь ветку для QProgressBar.

В create_widget(entity)

Если entity.type == "QProgressBar":

создавай QProgressBar


В apply_properties(widget, entity)

Применяй:

1. setMinimum(...)


2. setMaximum(...)


3. setValue(...)


4. setTextVisible(...)



Порядок применения обязателен

Применяй именно так:

1. minimum


2. maximum


3. value


4. text_visible



Почему это важно

Сначала фиксируй диапазон, потом значение.
Иначе виджет может автоматически скорректировать value, и canvas уйдет в рассинхрон с документом.


---

8. Сделай refresh для QProgressBar

Проверь, что refresh_widget(widget, entity) или аналогичный метод корректно переустанавливает:

minimum

maximum

value

text_visible


После изменения свойств из PropertyPanel прогрессбар на canvas должен обновляться без пересоздания всего canvas.

10. Нормализуй flow изменений из PropertyPanel

Изменения должны идти только через контроллер.

Для value

update_entity_property(entity_id, "value", new_value)


Для minimum

update_entity_property(entity_id, "minimum", new_value)


Для maximum

update_entity_property(entity_id, "maximum", new_value)


Для text_visible

update_entity_property(entity_id, "text_visible", new_value)


После каждого изменения должен проходить единый pipeline:

1. изменение в документе


2. flush_json_snapshot()


3. canvas.refresh_view(entity_id)


4. property_panel.rebuild()




---

11. Добавь нормализацию свойств QProgressBar

Сделай отдельный helper.
Не смешивай его с QSpinBox и QSlider.

Например:

_normalize_progress_bar_properties(properties: dict) -> dict


Правило 1

Если minimum > maximum:

при установке minimum подними maximum = minimum

при установке maximum опусти minimum = maximum


Правило 2

Если value < minimum:

ставь value = minimum


Правило 3

Если value > maximum:

ставь value = maximum


Правило 4

Если text_visible не bool:

приводи к bool


Применяй этот helper:

после property update

при JSON load

при Python import

12. Проверь работу CanvasEditor

QProgressBar не требует специального item view.
Он должен работать через обычный LeafItemView.

Проверь, что он:

создается на canvas

выбирается

двигается

меняет размер

не ломает overlay

корректно обновляется после property changes


Если есть сбой, исправляй на уровне:

WidgetFactory

LeafItemView

refresh pipeline


Не вводи новый специальный view-класс.


---

13. Проверь serializer

QProgressBar не требует специальных JSON-веток.

Убедись, что в JSON попадают свойства в таком виде:

"properties": {
  "value": 40,
  "minimum": 0,
  "maximum": 100,
  "text_visible": true
}

Проверь:

числа остаются числами

text_visible остается bool

14. Добавь экспорт QProgressBar в PythonExporter

В exporter добавь отдельную ветку для QProgressBar.

Генерируй

1. создание объекта


2. setObjectName(...)


3. setGeometry(...)


4. setMinimum(...)


5. setMaximum(...)


6. setValue(...)


7. setTextVisible(...)



Пример

self.progress_bar_1 = QProgressBar(self)
self.progress_bar_1.setObjectName("progress_bar_1")
self.progress_bar_1.setGeometry(100, 80, 140, 24)
self.progress_bar_1.setMinimum(0)
self.progress_bar_1.setMaximum(100)
self.progress_bar_1.setValue(40)
self.progress_bar_1.setTextVisible(True)

Порядок тоже фиксируй

Сначала диапазон, потом значение, потом видимость текста.

19. Зафиксируй критерий завершения QProgressBar

Считай QProgressBar полностью подключенным только если одновременно верно:

он есть в палитре

он создается drag&drop

он корректно отображается

его можно выбрать

его можно двигать и ресайзить

его свойства редактируются через PropertyPanel

свойства сохраняются в JSON

свойства экспортируются в Python

свойства импортируются обратно

round-trip не теряет структуру и значения

он стабильно работает внутри уже поддержанных контейнеров
