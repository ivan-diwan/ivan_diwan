Девятая рабочая контрольная точка

Собери строго это состояние:

работает QWizard как special-container

при добавлении QWizard автоматически создаются две WizardPage

WizardPage не видны в палитре и не выбираются как обычные объекты формы

активная страница управляется через PropertyPanel и через сам QWizard

обычные объекты можно бросать в активную страницу

реальные дочерние объекты живут в WizardPage, а не напрямую в QWizard

можно добавлять страницы

можно удалять страницы

можно переименовывать страницы

можно менять title и subtitle страницы

можно переключать активную страницу

корректно обновляется JSON snapshot

корректно удаляется QWizard вместе со всеми страницами и содержимым


После этого переходи к полной доводке PropertyPanel, а не сразу к Python exporter.


---

1. Цель девятой контрольной точки

Закрой последний из ключевых special-container типов.

Пользователь должен мочь:

1. добавить QWizard


2. увидеть две страницы


3. редактировать title и subtitle страниц


4. переключать активную страницу


5. добавлять объекты в первую страницу


6. переходить на вторую страницу


7. добавлять туда другие объекты


8. удалять страницы


9. удалять весь QWizard вместе со всем содержимым

4. Реализация create_wizard(...)

Сделай строго так:

1. создать сущность QWizard


2. задать свойства:

window_title = "Wizard"

current_index = 0



3. создать первую WizardPage


4. создать вторую WizardPage


5. назначить им:

parent_id = wizard_id

order = 0 и order = 1

properties["title"] = "Page 1" и "Page 2"

properties["subtitle"] = ""



6. пометить документ dirty


7. вернуть QWizard




---

5. Реализация add_wizard_page(...)

Сделай:

1. проверить существование QWizard


2. получить текущие WizardPage


3. вычислить следующий order


4. создать новую WizardPage


5. задать:

title, если передан

иначе "Page N"

subtitle, если передан

иначе ""



6. сделать новую страницу активной


7. пометить документ dirty


8. вернуть созданную страницу




---

6. Реализация remove_wizard_page(...)

Сделай аккуратно.

Алгоритм

1. проверить существование QWizard


2. проверить, что wizard_page_id действительно child этого QWizard


3. удалить все дочерние объекты WizardPage


4. удалить саму WizardPage


5. перестроить order оставшихся страниц


6. скорректировать current_index




---

Ограничение

Не разрешай удалить последнюю страницу.

Зафиксируй правило:

у QWizard должна оставаться минимум одна WizardPage

16. Подключи переключение активной страницы wizard

Сделай двустороннюю синхронизацию.


---

Если пользователь меняет страницу внутри QWizard

1. WizardItemView ловит смену страницы


2. сообщает CanvasEditor


3. canvas передает контроллеру


4. контроллер вызывает set_current_wizard_page(...)


5. документ обновляется


6. JSON обновляется




---

Если пользователь меняет страницу через PropertyPanel

1. PropertyPanel вызывает контроллер


2. контроллер меняет документ


3. canvas обновляет QWizard
