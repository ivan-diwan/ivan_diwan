Подэтап Q — QLCDNumber


---

1. Модель

type_name: QLCDNumber
qt_class: QLCDNumber
palette_group: Display
default_size: 120x50


---

2. Свойства

value: int = 0
digit_count: int = 5


---

3. Нормализация

digit_count >= 1

value:
  приведение к int

(ограничение по длине не вводим — Qt сам обрежет визуально)


---

4. Factory

create

QLCDNumber()

apply (порядок)

setDigitCount(digit_count)
display(value)


---

5. PropertyPanel

value → QSpinBox
digit_count → QSpinBox


---

6. Export

QLCDNumber
setDigitCount
display

пример

self.lcd_number_1 = QLCDNumber(self)
self.lcd_number_1.setGeometry(100, 80, 120, 50)
self.lcd_number_1.setDigitCount(5)
self.lcd_number_1.display(123)


---

7. Import

Парсить:

setDigitCount
display


---

8. Проверки

1. создание
2. изменение value
3. изменение digit_count
4. большие значения → не ломаются
5. JSON round-trip
6. Python round-trip
7. вложенные контейнеры

Подэтап R — QListView


---

1. Модель

type_name: QListView
qt_class: QListView
palette_group: Data
default_size: 180x120


---

2. Свойства

model_items: list[str] = []


---

3. Нормализация

если не список → []
каждый элемент → str


---

4. Factory

create

QListView()

apply

создать QStringListModel
setStringList(model_items)
setModel(model)


---

5. PropertyPanel

model_items → string_list


---

6. Export

(упрощенная модель)

QStringListModel
setStringList
setModel

пример

self.list_view_1 = QListView(self)
self.list_view_1.setGeometry(100, 80, 180, 120)

model = QStringListModel()
model.setStringList(["A", "B", "C"])
self.list_view_1.setModel(model)


---

7. Import

setModel
