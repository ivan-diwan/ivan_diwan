Подэтап M — QCalendarWidget

Подключай QCalendarWidget сразу после полного закрытия QDateTimeEdit.
Архитектуру не меняй. Повтори тот же pipeline, но для календарного leaf-виджета с нормализованной датой.


---

1. Цель подэтапа

Добейся, чтобы QCalendarWidget проходил полный цикл:

есть в палитре

создается на форме

выбирается

двигается

меняет размер

редактируется через PropertyPanel

сохраняется в JSON

экспортируется в .py

импортируется обратно

проходит round-trip без потери geometry и свойств



---

2. Зафиксируй модель QCalendarWidget

Считай QCalendarWidget обычным leaf-объектом.

Тип

type_name = "QCalendarWidget"


Роль

editor_kind = "leaf"


Палитра

palette_visible = true

palette_group = "Date and Time"


Поведение

movable = true

resizable = true

deletable_directly = true


Qt-класс

qt_class_name = "QCalendarWidget"



---

3. Зафиксируй минимальный набор свойств

Подключай только устойчивую базу.

Обязательные свойства

selected_date: str

minimum_date: str

maximum_date: str


Формат хранения

Храни даты только в формате:

YYYY-MM-DD


Примеры:

2026-04-08

2025-01-01



---

Значения по умолчанию

Зафиксируй:

selected_date = "2026-01-01"

minimum_date = "1900-01-01"

maximum_date = "2100-12-31"



---

Что пока не подключай

Не добавляй на этом подэтапе:

grid_visible

navigation_bar_visible

horizontal_header_format

vertical_header_format

first_day_of_week

date_edit_enabled

date_edit_accept_delay


Сначала закрой устойчивую базу.

7. Используй уже существующий date-helper

Для QCalendarWidget не делай новый формат даты.
Используй тот же date-helper, что и для QDateEdit.

Должны уже существовать:

parse_date_string(value: str) -> date | None

format_date_string(value: date) -> str

is_valid_date_string(value: str) -> bool

normalize_date_string(value: str, fallback: str) -> str



---

Правило

Во всей системе дата хранится как строка:

YYYY-MM-DD


А в Qt преобразуется в:

QDate



---

8. Добавь нормализацию свойств QCalendarWidget

Сделай отдельный helper.

Например:

_normalize_calendar_widget_properties(properties: dict) -> dict


Правило 1

Если selected_date отсутствует или невалидна:

ставь дефолтную дату


Правило 2

Если minimum_date отсутствует или невалидна:

ставь "1900-01-01"


Правило 3

Если maximum_date отсутствует или невалидна:

ставь "2100-12-31"


Правило 4

Если minimum_date > maximum_date:

при установке minimum_date подними maximum_date = minimum_date

при установке maximum_date опусти minimum_date = maximum_date


Правило 5

Если selected_date < minimum_date:

ставь selected_date = minimum_date


Правило 6

Если selected_date > maximum_date:

ставь selected_date = maximum_date

9. Добавь QCalendarWidget в WidgetFactory

В factory/widget_factory.py добавь отдельную ветку.

В create_widget(entity)

Если entity.type == "QCalendarWidget":

создавай QCalendarWidget


В apply_properties(widget, entity)

Применяй:

1. setMinimumDate(...)


2. setMaximumDate(...)


3. setSelectedDate(...)




---

Порядок применения обязателен

Применяй именно так:

1. minimum


2. maximum


3. selected date




---

Почему это важно

Сначала фиксируй диапазон, потом выбранную дату.
Иначе виджет может скорректировать значение сам.

Преобразование строк в QDate

Используй уже существующий helper:

_to_qdate(value: str) -> QDate

12. Нормализуй flow изменений из PropertyPanel

Изменения должны идти только через контроллер.

Для selected_date

update_entity_property(entity_id, "selected_date", new_value)


Для minimum_date

update_entity_property(entity_id, "minimum_date", new_value)


Для maximum_date

update_entity_property(entity_id, "maximum_date", new_value)


После каждого изменения должен проходить единый pipeline:

1. изменение в документе


2. нормализация date-свойств


3. flush_json_snapshot()


4. canvas.refresh_view(entity_id)


5. property_panel.rebuild()

14. Проверь serializer

QCalendarWidget не требует специальных JSON-веток.

Убедись, что в JSON попадают свойства в таком виде:

"properties": {
  "selected_date": "2026-04-08",
  "minimum_date": "2020-01-01",
  "maximum_date": "2030-12-31"
}

Проверь:

значения хранятся именно как строки

формат единый

JSON round-trip не меняет представление даты

15. Добавь экспорт QCalendarWidget в PythonExporter

В exporter добавь отдельную ветку для QCalendarWidget.

Генерируй

1. создание объекта


2. setObjectName(...)


3. setGeometry(...)


4. setMinimumDate(QDate(...))


5. setMaximumDate(QDate(...))


6. setSelectedDate(QDate(...))




---

Пример

self.calendar_widget_1 = QCalendarWidget(self)
self.calendar_widget_1.setObjectName("calendar_widget_1")
self.calendar_widget_1.setGeometry(100, 80, 260, 200)
self.calendar_widget_1.setMinimumDate(QDate(2020, 1, 1))
self.calendar_widget_1.setMaximumDate(QDate(2030, 12, 31))
self.calendar_widget_1.setSelectedDate(QDate(2026, 4, 8))


---

Импорты

Если в документе есть QCalendarWidget, добавляй импорт:

QCalendarWidget из QtWidgets

QDate из QtCore
