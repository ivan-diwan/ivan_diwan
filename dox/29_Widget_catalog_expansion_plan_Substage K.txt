Подэтап K — QTimeEdit

Подключай QTimeEdit сразу после полного закрытия QDateEdit.
Архитектуру не меняй. Повтори тот же pipeline, но для времени в нормализованной строковой форме.


---

1. Цель подэтапа

Добейся, чтобы QTimeEdit проходил полный цикл:

есть в палитре

создается на форме

выбирается

двигается

меняет размер

редактируется через PropertyPanel

сохраняется в JSON

экспортируется в .py

импортируется обратно

проходит round-trip без потери geometry и свойств



---

2. Зафиксируй модель QTimeEdit

Считай QTimeEdit обычным leaf-объектом.

Тип

type_name = "QTimeEdit"


Роль

editor_kind = "leaf"


Палитра

palette_visible = true

palette_group = "Date and Time"


Поведение

movable = true

resizable = true

deletable_directly = true


Qt-класс

qt_class_name = "QTimeEdit"



---

3. Зафиксируй минимальный набор свойств

Подключай только устойчивую базу.

Обязательные свойства

time: str

minimum_time: str

maximum_time: str


Формат хранения

Храни время только в формате:

HH:MM:SS


Примеры:

09:30:00

23:59:59

00:00:00



---

Значения по умолчанию

Зафиксируй:

time = "12:00:00"

minimum_time = "00:00:00"

maximum_time = "23:59:59"



---

Что пока не подключай

Не добавляй на этом подэтапе:

display_format

special_value_text

wrapping

секции времени отдельно

локализацию формата времени


Сначала закрой устойчивую базу.


---

6. Подключи создание QTimeEdit в FormDocument

Специальной логики создания не нужно.

Проверь, что при создании:

берется default_size

7. Добавь отдельный helper для времени

Сделай единый набор функций для работы со временем.
Не разбрасывай парсинг строк по коду.

Например создай:

parse_time_string(value: str) -> time | None

format_time_string(value: time) -> str

is_valid_time_string(value: str) -> bool

normalize_time_string(value: str, fallback: str) -> str



---

Правило

Во всей системе время хранится как строка:

HH:MM:SS


А в Qt преобразуется в:

QTime



---

8. Добавь нормализацию свойств QTimeEdit

Сделай отдельный helper.

Например:

_normalize_time_edit_properties(properties: dict) -> dict


Правило 1

Если time отсутствует или невалидно:

ставь дефолтное время


Правило 2

Если minimum_time отсутствует или невалидно:

ставь "00:00:00"


Правило 3

Если maximum_time отсутствует или невалидно:

ставь "23:59:59"


Правило 4

Если minimum_time > maximum_time:

при установке minimum_time подними maximum_time = minimum_time

при установке maximum_time опусти minimum_time = maximum_time


Правило 5

Если time < minimum_time:

ставь time = minimum_time


Правило 6

Если time > maximum_time:

ставь time = maximum_time



---

9. Добавь QTimeEdit в WidgetFactory

В factory/widget_factory.py добавь отдельную ветку.

В create_widget(entity)

Если entity.type == "QTimeEdit":

создавай QTimeEdit


В apply_properties(widget, entity)

Применяй:

1. setMinimumTime(...)


2. setMaximumTime(...)


3. setTime(...)




---

Порядок применения обязателен

Применяй именно так:

1. minimum


2. maximum


3. current time




---

Почему это важно

Сначала фиксируй диапазон, потом текущее время.
Иначе виджет может скорректировать значение сам.


---

Преобразование строк в QTime

Сделай helper:

_to_qtime(value: str) -> QTime


Используй единый формат:

HH:MM:SS

12. Нормализуй flow изменений из PropertyPanel

Изменения должны идти только через контроллер.

Для time

update_entity_property(entity_id, "time", new_value)


Для minimum_time

update_entity_property(entity_id, "minimum_time", new_value)


Для maximum_time

update_entity_property(entity_id, "maximum_time", new_value)


После каждого изменения должен проходить единый pipeline:

1. изменение в документе


2. нормализация time-свойств


3. flush_json_snapshot()


4. canvas.refresh_view(entity_id)


5. property_panel.rebuild()

13. Проверь работу CanvasEditor

QTimeEdit не требует специального item view.

Проверь, что он:

не ломает overlay

корректно обновляется после property changes

14. Проверь serializer

QTimeEdit не требует специальных JSON-веток.

Убедись, что в JSON попадают свойства в таком виде:

"properties": {
  "time": "09:30:00",
  "minimum_time": "08:00:00",
  "maximum_time": "18:00:00"
}

Проверь:

значения хранятся именно как строки

формат единый

JSON round-trip не меняет представление времени

15. Добавь экспорт QTimeEdit в PythonExporter

В exporter добавь отдельную ветку для QTimeEdit.

Генерируй

1. создание объекта


2. setObjectName(...)


3. setGeometry(...)


4. setMinimumTime(QTime(...))


5. setMaximumTime(QTime(...))


6. setTime(QTime(...))




---

Пример

self.time_edit_1 = QTimeEdit(self)
self.time_edit_1.setObjectName("time_edit_1")
self.time_edit_1.setGeometry(100, 80, 120, 26)
self.time_edit_1.setMinimumTime(QTime(8, 0, 0))
self.time_edit_1.setMaximumTime(QTime(18, 0, 0))
self.time_edit_1.setTime(QTime(9, 30, 0))


---

Импорты

Если в документе есть QTimeEdit, добавляй импорт:

QTimeEdit из QtWidgets

QTime из QtCore

22. Зафиксируй критерий завершения QTimeEdit

Считай QTimeEdit полностью подключенным только если одновременно верно:

он есть в палитре

он создается drag&drop

он корректно отображается
