Седьмая рабочая контрольная точка

Собери строго это состояние:

работает QToolBox как следующий special-container

при добавлении QToolBox автоматически создаются две ToolPage

ToolPage не видны в палитре и не выбираются как обычные объекты формы

активная секция управляется через сам QToolBox и через PropertyPanel

обычные объекты можно бросать в активную секцию

реальные дочерние объекты живут в ToolPage, а не напрямую в QToolBox

можно добавлять секции

можно удалять секции

можно переименовывать секции

можно переключать активную секцию

корректно обновляется JSON snapshot

корректно удаляется QToolBox вместе со всеми секциями и содержимым


Не переходи к QSplitter, пока этот блок не станет устойчивым.


---

1. Цель седьмой контрольной точки

Закрой еще один page-based контейнер, но уже с вертикальными секциями.

Пользователь должен мочь:

1. добавить QToolBox


2. увидеть две секции


3. переименовать секции


4. переключать активную секцию


5. добавлять объекты в первую секцию


6. переключаться на вторую секцию


7. добавлять туда другие объекты


8. удалять секции


9. удалять весь QToolBox вместе со всем содержимым

4. Реализация create_toolbox(...)

Сделай строго так:

1. создать сущность QToolBox


2. задать свойства:

current_index = 0



3. создать первую ToolPage


4. создать вторую ToolPage


5. назначить им:

parent_id = toolbox_id

order = 0 и order = 1

properties["title"] = "Section 1" и "Section 2"



6. пометить документ dirty


7. вернуть QToolBox




---

5. Реализация add_tool_page(...)

Сделай:

1. проверить существование QToolBox


2. получить текущие ToolPage


3. вычислить следующий order


4. создать новую ToolPage


5. задать title

если передан — использовать

если нет — "Section N"



6. сделать новую секцию активной


7. пометить документ dirty


8. вернуть созданную ToolPage




---

6. Реализация remove_tool_page(...)

Сделай аккуратно.

Алгоритм

1. проверить существование QToolBox


2. проверить, что tool_page_id действительно child этого QToolBox


3. удалить все дочерние объекты ToolPage


4. удалить саму ToolPage


5. перестроить order оставшихся секций


6. скорректировать current_index




---

Ограничение

Не разрешай удалить последнюю секцию.

Зафиксируй правило:

у QToolBox должна оставаться минимум одна ToolPage

14. Реализуй rebuild_pages(...) у ToolBoxItemView

Сделай так:

1. очистить текущие секции в QToolBox


2. получить ToolPage из документа


3. отсортировать по order


4. для каждой секции:

создать внутренний QWidget

добавить его в QToolBox с title

сохранить соответствие:

tool_page_id -> page_widget




5. выставить активную секцию по current_index

16. Подключи переключение активной секции

Сделай двустороннюю синхронизацию.


---

Если пользователь переключает секцию мышью в QToolBox

1. ToolBoxItemView ловит смену индекса


2. сообщает CanvasEditor


3. canvas передает контроллеру


4. контроллер вызывает set_current_tool_page(...)


5. документ обновляется


6. JSON обновляется




---

Если пользователь меняет current_index через PropertyPanel

1. PropertyPanel вызывает контроллер


2. контроллер меняет документ


3. canvas обновляет QToolBox
