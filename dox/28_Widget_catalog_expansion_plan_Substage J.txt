Подэтап J — QDateEdit

Подключай QDateEdit как первый тип из очереди даты и времени.
Не меняй архитектуру. Повтори тот же pipeline, но с учетом хранения даты в нормализованной строковой форме.


---

1. Цель подэтапа

Добейся, чтобы QDateEdit проходил полный цикл:

есть в палитре

создается на форме

выбирается

двигается

меняет размер

редактируется через PropertyPanel

сохраняется в JSON

экспортируется в .py

импортируется обратно

проходит round-trip без потери geometry и свойств



---

2. Зафиксируй модель QDateEdit

Считай QDateEdit обычным leaf-объектом.

Тип

type_name = "QDateEdit"


Роль

editor_kind = "leaf"


Палитра

palette_visible = true

palette_group = "Date and Time"


Поведение

movable = true

resizable = true

deletable_directly = true


Qt-класс

qt_class_name = "QDateEdit"



---

3. Зафиксируй минимальный набор свойств

Подключай только устойчивую базу.

Обязательные свойства

date: str

minimum_date: str

maximum_date: str


Формат хранения

Храни даты только в формате:

YYYY-MM-DD


Примеры:

2026-04-08

2025-01-01



---

Значения по умолчанию

Зафиксируй:

date = "2026-01-01"

minimum_date = "1900-01-01"

maximum_date = "2100-12-31"


Можно выбрать другой дефолтный date, но он должен быть:

валидным

в том же формате

не выходить за диапазон



---

Что пока не подключай

Не добавляй на этом подэтапе:

display_format

calendar_popup

special_value_text

wrapping

локализацию формата даты


Сначала закрой устойчивую базу.


---

7. Добавь отдельный helper для даты

Сделай единый набор функций для работы с датой.
Не разбрасывай парсинг строк по коду.

Например в utils или отдельном helper-модуле создай:

parse_date_string(value: str) -> date | None

format_date_string(value: date) -> str

is_valid_date_string(value: str) -> bool

normalize_date_string(value: str, fallback: str) -> str



---

Правило

Во всей системе дата хранится как строка:

YYYY-MM-DD


А в Qt преобразуется в:

QDate



---

8. Добавь нормализацию свойств QDateEdit

Сделай отдельный helper.

Например:

_normalize_date_edit_properties(properties: dict) -> dict


Правило 1

Если date отсутствует или невалидна:

ставь дефолтную дату


Правило 2

Если minimum_date отсутствует или невалидна:

ставь "1900-01-01"


Правило 3

Если maximum_date отсутствует или невалидна:

ставь "2100-12-31"


Правило 4

Если minimum_date > maximum_date:

при установке minimum_date подними maximum_date = minimum_date

при установке maximum_date опусти minimum_date = maximum_date


Правило 5

Если date < minimum_date:

ставь date = minimum_date


Правило 6

Если date > maximum_date:

ставь date = maximum_date



---

9. Добавь QDateEdit в WidgetFactory

В factory/widget_factory.py добавь отдельную ветку.

В create_widget(entity)

Если entity.type == "QDateEdit":

создавай QDateEdit


В apply_properties(widget, entity)

Применяй:

1. setMinimumDate(...)


2. setMaximumDate(...)


3. setDate(...)




---

Порядок применения обязателен

Применяй именно так:

1. minimum


2. maximum


3. current date




---

Почему это важно

Сначала фиксируй диапазон, потом текущую дату.
Иначе виджет может скорректировать дату сам.


---

Преобразование строк в QDate

Сделай helper:

_to_qdate(value: str) -> QDate


Используй единый формат:

YYYY-MM-DD

12. Нормализуй flow изменений из PropertyPanel

Изменения должны идти только через контроллер.

Для date

update_entity_property(entity_id, "date", new_value)


Для minimum_date

update_entity_property(entity_id, "minimum_date", new_value)


Для maximum_date

update_entity_property(entity_id, "maximum_date", new_value)


После каждого изменения должен проходить единый pipeline:

1. изменение в документе


2. нормализация date-свойств


3. flush_json_snapshot()


4. canvas.refresh_view(entity_id)


5. property_panel.rebuild()

14. Проверь serializer

QDateEdit не требует специальных JSON-веток.

Убедись, что в JSON попадают свойства в таком виде:

"properties": {
  "date": "2026-04-08",
  "minimum_date": "2020-01-01",
  "maximum_date": "2030-12-31"
}

Проверь:

значения хранятся именно как строки

формат единый

JSON round-trip не меняет представление даты

15. Добавь экспорт QDateEdit в PythonExporter

В exporter добавь отдельную ветку для QDateEdit.

Генерируй

1. создание объекта


2. setObjectName(...)


3. setGeometry(...)


4. setMinimumDate(QDate(...))


5. setMaximumDate(QDate(...))


6. setDate(QDate(...))




---

Пример

self.date_edit_1 = QDateEdit(self)
self.date_edit_1.setObjectName("date_edit_1")
self.date_edit_1.setGeometry(100, 80, 120, 26)
self.date_edit_1.setMinimumDate(QDate(2020, 1, 1))
self.date_edit_1.setMaximumDate(QDate(2030, 12, 31))
self.date_edit_1.setDate(QDate(2026, 4, 8))


---

Импорты

Если в документе есть QDateEdit, добавляй импорт:

QDateEdit из QtWidgets

QDate из QtCore
