Подэтап F — QPlainTextEdit

Подключай QPlainTextEdit сразу после полного закрытия QTextEdit.
Архитектуру не меняй. Повтори тот же pipeline для plain-text редактора.


---

1. Цель подэтапа

Добейся, чтобы QPlainTextEdit проходил полный цикл:

есть в палитре

создается на форме

выбирается

двигается

меняет размер

редактируется через PropertyPanel

сохраняется в JSON

экспортируется в .py

импортируется обратно

проходит round-trip без потери geometry и свойств



---

2. Зафиксируй модель QPlainTextEdit

Считай QPlainTextEdit обычным leaf-объектом.

Тип

type_name = "QPlainTextEdit"


Роль

editor_kind = "leaf"


Палитра

palette_visible = true

palette_group = "Text"


Поведение

movable = true

resizable = true

deletable_directly = true


Qt-класс

qt_class_name = "QPlainTextEdit"



---

3. Зафиксируй минимальный набор свойств

Подключай ту же устойчивую базу, что и для QTextEdit.

Обязательные свойства

text: str

placeholder: str

read_only: bool


Значения по умолчанию

text = ""

placeholder = ""

read_only = false


Что пока не подключай

line_wrap_mode

tab_changes_focus

undo_redo_enabled

overwrite_mode

background_visible

center_on_scroll


Сначала закрой базовый рабочий уровень.

7. Добавь QPlainTextEdit в WidgetFactory

В factory/widget_factory.py добавь отдельную ветку.

В create_widget(entity)

Если entity.type == "QPlainTextEdit":

создавай QPlainTextEdit


В apply_properties(widget, entity)

Применяй:

1. setReadOnly(...)


2. setPlaceholderText(...)


3. setPlainText(...)




---

Почему именно так

Сначала фиксируй режим редактирования, потом placeholder, потом текст.


---

Принцип

Содержимое всегда трактуй как обычный plain text.

10. Нормализуй flow изменений из PropertyPanel

Изменения должны идти только через контроллер.

Для text

update_entity_property(entity_id, "text", new_value)


Для placeholder

update_entity_property(entity_id, "placeholder", new_value)


Для read_only

update_entity_property(entity_id, "read_only", new_value)


После каждого изменения должен проходить единый pipeline:

1. изменение в документе


2. flush_json_snapshot()


3. canvas.refresh_view(entity_id)


4. property_panel.rebuild()




---

11. Добавь нормализацию свойств QPlainTextEdit

Сделай отдельный helper.

Например:

_normalize_plain_text_edit_properties(properties: dict) -> dict


Правило 1

Если text отсутствует:

ставь ""


Правило 2

Если placeholder отсутствует:

ставь ""


Правило 3

Если read_only не bool:

приводи к bool


Правило 4

Все текстовые значения приводи к str

Применяй helper:

после property update

при JSON load

при Python import

12. Проверь работу CanvasEditor

QPlainTextEdit не требует специального item view.

13. Проверь serializer

QPlainTextEdit не требует специальных JSON-веток.

Убедись, что в JSON попадают свойства в таком виде:

"properties": {
  "text": "Строка 1\nСтрока 2",
  "placeholder": "Введите текст",
  "read_only": false
}

Проверь:

переводы строк сохраняются корректно

текст остается строкой

read_only остается bool

14. Добавь экспорт QPlainTextEdit в PythonExporter

В exporter добавь отдельную ветку для QPlainTextEdit.

Генерируй

1. создание объекта


2. setObjectName(...)


3. setGeometry(...)


4. setReadOnly(...)


5. setPlaceholderText(...) — если не пусто


6. setPlainText(...) — если текст не пуст



Пример

self.plain_text_edit_1 = QPlainTextEdit(self)
self.plain_text_edit_1.setObjectName("plain_text_edit_1")
self.plain_text_edit_1.setGeometry(100, 80, 180, 90)
self.plain_text_edit_1.setReadOnly(False)
self.plain_text_edit_1.setPlaceholderText("Введите текст")
self.plain_text_edit_1.setPlainText("Строка 1\nСтрока 2")
