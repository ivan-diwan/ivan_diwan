Первый пакет файлов. Порядок написания

Пиши файлы не параллельно, а в этом порядке.


---

1. document/models.py

Начни с моделей данных.
Сначала зафиксируй структуры, потом все остальное.

Создай классы

EntityModel


В FormRootModel зафиксируй поля

id

type

name

root_widget_type

width

height

window_title


В EntityModel зафиксируй поля

id

type

parent_id

name

order

geometry

properties


Минимальные методы

EntityModel

to_dict()

from_dict(data)


FormRootModel

to_dict()

from_dict(data)


Требование

Сразу сделай модели пригодными:

для хранения в памяти

для сериализации в dict

для восстановления из dict



---

2. utils/ids.py

После моделей сделай генерацию идентификаторов.

Создай

IdGenerator


Минимальные методы

next(prefix: str) -> str

reset()


Правило

Формат id должен быть стабильным.

Пример:

label_1

push_button_1

group_box_1

tab_page_1



---

3. utils/naming.py

Сразу после id сделай генерацию имен.

Создай функции

make_default_name(prefix: str, index: int) -> str

make_unique_name(existing_names: set[str], prefix: str) -> str


Правило

name и id не смешивай.

Пример:

id = obj_push_button_1

name = push_button_1


или единообразно:

id = push_button_1

name = push_button_1


Но выбери один подход и не меняй его потом.

---

Первая обязательная рабочая цель

Добейся следующего состояния:

Должно работать

приложение запускается

есть левое окно

кнопка Создать создает новый FormDocument

открывается отдельное FormWindow

в canvas видна пустая форма заданного размера

панель свойств показывает свойства формы

JSON snapshot можно сформировать и сохранить


Пока этого не добьешься, не переходи к drag&drop и визуальным объектам.

открывается отдельное окно пустой формы
