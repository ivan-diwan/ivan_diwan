План расширения каталога виджетов

Подключай новые типы только полным циклом.
Не считай виджет добавленным, пока он не проходит:

1. WidgetRegistry


2. PropertyPanel


3. WidgetFactory


4. CanvasEditor


5. FormSerializer


6. PythonExporter


7. PythonImporter


8. round-trip проверку



Ниже — порядок и правила подключения следующей очереди типов.


---

1. Общий порядок следующей очереди

Подключай в таком порядке:

1. QSpinBox


2. QDoubleSpinBox


3. QSlider


4. QProgressBar


5. QTextEdit


6. QPlainTextEdit


7. QListWidget


8. QTableWidget

Не подключай одновременно несколько новых типов, пока предыдущий не закрыт полностью.

Для каждого нового типа соблюдай один и тот же шаблон.

Шаг 2. Поддержка в WidgetFactory

Добавь:

применение geometry

применение всех поддержанных свойств



---

Шаг 3. Поддержка в PropertyPanel

Добавь отображение:

основного блока

типозависимых свойств


Для каждого свойства используй правильный редактор через PropertyEditorFactory.


---

Шаг 4. Поддержка в serializer

Проверь, что свойства стабильно сохраняются в JSON и читаются обратно.


---

Шаг 5. Поддержка в exporter

Добавь генерацию Python-кода:

применение geometry

применение свойств



---

Шаг 6. Поддержка в importer

Добавь обратное распознавание:

создания объекта

geometry

свойств



---

Шаг 7. Тестирование

Прогони цикл:

1. создать объект в редакторе


2. изменить свойства


3. сохранить JSON


4. загрузить JSON


5. экспортировать .py


6. импортировать .py

3. Подключение QSpinBox

Подключай первым.


---

3.1. Registry

Добавь тип QSpinBox.

Свойства

value: int

minimum: int

maximum: int

step: int

prefix: str

suffix: str


Значения по умолчанию

value = 0

minimum = 0

maximum = 99

step = 1

prefix = ""

suffix = ""


default_size

Например:

width = 100

height = 26


Родители

Разреши:

FormRoot

QWidget

QFrame

QGroupBox

TabPage

StackPage

ToolPage

WizardPage

ContainerContent

SplitterPane



---

3.2. PropertyPanel

Показывай:

value

minimum

maximum

step

prefix

suffix


Редакторы

value → QSpinBox

minimum → QSpinBox

maximum → QSpinBox

step → QSpinBox

prefix → QLineEdit

suffix → QLineEdit



---

3.3. WidgetFactory

Создавай QSpinBox.

Применяй:

setMinimum(...)

setMaximum(...)

setSingleStep(...)

setPrefix(...)

setSuffix(...)

setValue(...)


Применяй свойства в таком порядке:

1. minimum


2. maximum


3. step


4. prefix


5. suffix


6. value



Сначала всегда ставь диапазон, потом значение.


---

3.4. Exporter

Генерируй:

self.spin_box_1 = QSpinBox(self)
self.spin_box_1.setObjectName("spin_box_1")
self.spin_box_1.setGeometry(x, y, w, h)
self.spin_box_1.setMinimum(0)
self.spin_box_1.setMaximum(99)
self.spin_box_1.setSingleStep(1)
self.spin_box_1.setPrefix("")
self.spin_box_1.setSuffix("")
self.spin_box_1.setValue(0)

Если prefix или suffix пустые, можешь:

либо не генерировать эти строки

либо генерировать всегда


Для стабильности лучше генерировать только отличающиеся от пустого значения, если exporter уже так устроен для других свойств.


---

3.5. Importer

Распознавай:

QSpinBox(parent)

setMinimum(...)

setMaximum(...)

setSingleStep(...)

setPrefix(...)

setSuffix(...)

setValue(...)


Восстанавливай свойства в документ.


---

3.6. Тесты для QSpinBox

Проверь:

Сценарий 1

создать QSpinBox

изменить value


Сценарий 2

изменить minimum, maximum, step


Сценарий 3

изменить prefix, suffix


Сценарий 4

JSON round-trip


Сценарий 5

Python export/import round-trip

12. Для каждого нового типа обновляй palette осознанно

Добавляй тип в палитру только после того, как он уже проходит:

создание

свойства

экспорт

импорт


До этого можешь держать palette_visible = false на стадии внутренней разработки.


---

13. Для каждого нового типа обновляй exporter/importer одновременно

Не допускай ситуации:

тип уже можно создать в редакторе

но exporter/importer его не понимает


Если тип появился в палитре, он обязан пройти полный pipeline.


---

14. Зафиксируй контрольный список на каждый новый тип

Перед тем как считать тип закрытым, проверь:

Документ

создается

хранится в JSON


UI

виден в палитре

создается на форме

выбирается

двигается

ресайзится

удаляется


Свойства

показываются

редактируются

обновляют canvas


Export/import

экспортируется

импортируется

проходит round-trip



---

15. Не подключай пока сложные модели данных

Не добавляй на этой очереди:

полноценное содержимое QTableWidget по ячейкам

полноценные tree items у QTreeWidget

data models для QListView/QTreeView/QTableView


Сначала подключай только базовый уровень конфигурации этих виджетов.

17. Дальше держи только маленькие итерации

На одном подэтапе подключай не больше:
