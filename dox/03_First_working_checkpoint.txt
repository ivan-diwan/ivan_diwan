Первая рабочая контрольная точка

Собери строго это состояние:

приложение запускается

есть левое главное окно

работает кнопка Создать

создается новый пустой FormDocument

открывается отдельное окно формы

в нем видна пустая форма заданного размера

слева в панели свойств показываются свойства формы

можно сформировать корректный JSON snapshot


Ниже — минимальный обязательный набор классов, файлов и методов для этой точки.


---

4. utils/geometry.py

Сделай минимум.

Функции:

make_geometry(x: int, y: int, width: int, height: int) -> dict

Поведение:

11. document/form_document.py

Сделай центральную модель документа.

id_generator: IdGenerator


Внутри храни:

Реализуй методы чтения

get_entity(entity_id: str) -> EntityModel | None

has_entity(entity_id: str) -> bool

get_children(parent_id: str) -> list[EntityModel]

На первой контрольной точке get_descendants() можно тоже сделать, но он еще не критичен.


---

Реализуй методы состояния

mark_dirty() -> None

clear_dirty() -> None



---

Реализуй метод сериализации в модели

to_dict() -> dict


Этот метод может вызывать DocumentWriter, но для первой точки допустимо держать простой внутренний вызов serializer снаружи.
Главное — не дублируй логику бесконтрольно.


---

Реализуй classmethod или factory

@classmethod create_new(cls, registry, validator, id_generator, width=1200, height=800, root_widget_type="QWidget") -> FormDocument


Он должен:

создать FormRootModel

создать пустой FormDocument

вернуть готовый документ

Сделай минимальный рабочий контроллер.

Реализуй методы

new_document() -> FormDocument

Должен:

1. создать новый FormDocument через FormDocument.create_new(...)


2. записать его в state.active_document


3. очистить выбор


4. вернуть документ




---

get_active_document() -> FormDocument | None

Нужен для UI.


---

select_entity(entity_id: str | None) -> None

На первой точке достаточно:

если None → очистить выбор

если id есть → сохранить его в state.selected_entity_id



---

get_selected_entity() -> EntityModel | None

Вернуть выбранную сущность из документа.


---

flush_json_snapshot() -> dict

Пока сделай возврат dict через serializer.
Запись на диск можно пока подключить сразу, но для первой точки достаточно и in-memory snapshot + возможность сохранить в файл.


---

property mutations

drag/drop

page actions

25. Что должно заработать после завершения этого блока

Добейся строго следующего:

Сценарий

1. запустить приложение


2. увидеть левое окно редактора


3. нажать Создать


4. получить новый FormDocument


5. открыть отдельное окно формы


6. увидеть пустую форму размером 1200x800


7. увидеть в левой панели свойства формы:

name

root_widget_type

width

height

window_title



8. получить корректный JSON snapshot через контроллер/serializer

26. JSON на этой точке должен выглядеть так

{
  "meta": {
    "format_version": 1,
    "document_type": "pyside6_form"
  },
  "form": {
    "id": "form_root",
    "type": "FormRoot",
    "name": "form",
    "root_widget_type": "QWidget",
    "width": 1200,
    "height": 800,
    "window_title": ""
  },
  "objects": []
}

Добейся именно этого.

28. Критерий завершения контрольной точки

Считай этап закрытым только если одновременно выполняются все условия:

приложение стабильно запускается

Создать открывает отдельную форму

документ реально существует в контроллере

canvas показывает форму правильного размера

панель свойств показывает свойства формы

serializer дает валидный JSON

повторный вызов new_document() не ломает приложение
