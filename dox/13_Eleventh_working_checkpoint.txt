Одиннадцатая рабочая контрольная точка

Собери строго это состояние:

работает PythonExporter

экспорт строится только из FormDocument

формируется стабильный .py файл

экспортируются:

FormRoot

leaf-объекты

обычные контейнеры

QTabWidget

QScrollArea

QStackedWidget

QToolBox

QSplitter

QWizard


структура parent-child в Python соответствует документу

свойства объектов в Python соответствуют properties

geometry в Python соответствует geometry

внутренние сущности (TabPage, ContainerContent, StackPage, ToolPage, SplitterPane, WizardPage) не теряются, а корректно преобразуются в реальную PySide6-структуру

один и тот же документ при повторном экспорте дает предсказуемый и стабильный результат


Не переходи к PythonImporter, пока экспорт не станет устойчивым.


---

1. Цель одиннадцатой контрольной точки

Закрой полный экспорт формы в Python.

Пользователь должен мочь:

1. собрать форму в конструкторе


2. нажать Сохранить


3. получить .py файл


4. запустить этот .py файл


5. увидеть ту же форму, что собрана в редакторе

10. Введи единый способ получения Python parent reference

Сделай helper:

_get_parent_ref(entity) -> str



---

Правило

Если parent_id == form_root:

parent ref = self


Если родитель — обычный контейнер:

parent ref = self.<parent_name>


Если родитель — внутренняя сущность:

parent ref определяется через special-container mapping, а не напрямую по parent_id


Это ключевой момент exporter.

12. Экспорт QTabWidget

Сделай отдельную ветку exporter для QTabWidget.


---

Алгоритм

1. создать QTabWidget


2. задать geometry


3. задать tabs_closable


4. найти все TabPage


5. отсортировать по order


6. для каждой TabPage:

создать внутренний QWidget

задать ему objectName

добавить в QTabWidget через addTab(...)

использовать title из TabPage.properties["title"]



7. после создания вкладок выставить setCurrentIndex(...)


8. экспортировать дочерние объекты каждой TabPage внутрь соответствующего внутреннего widget




---

Что нужно хранить внутри exporter

Сделай внутренний mapping:

tab_page_id -> python_ref_name_of_tab_widget_page


Без этого не получится правильно экспортировать детей страниц.


---

Пример

self.tab_widget_1 = QTabWidget(self)
self.tab_widget_1.setObjectName("tab_widget_1")
self.tab_widget_1.setGeometry(100, 80, 400, 240)

self.tab_page_1 = QWidget()
self.tab_page_1.setObjectName("tab_page_1")
self.tab_widget_1.addTab(self.tab_page_1, "Tab 1")

self.tab_page_2 = QWidget()
self.tab_page_2.setObjectName("tab_page_2")
self.tab_widget_1.addTab(self.tab_page_2, "Tab 2")

self.tab_widget_1.setCurrentIndex(0)


---

21. Сделай единый helper применения geometry

_emit_geometry(entity, ref_name) -> list[str]



---

Правило

Для всех обычных widgets:

Для внутренних страниц:

geometry обычно не нужно явно применять как к обычным объектам, если это child special-container и layout определяется контейнером.

TabPage

StackPage

ToolPage

WizardPage

SplitterPane

ContainerContent
