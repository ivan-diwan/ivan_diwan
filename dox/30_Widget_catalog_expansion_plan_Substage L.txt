Подэтап L — QDateTimeEdit

Подключай QDateTimeEdit сразу после полного закрытия QTimeEdit.
Архитектуру не меняй. Повтори тот же pipeline, но для даты и времени в одной нормализованной строковой форме.


---

1. Цель подэтапа

Добейся, чтобы QDateTimeEdit проходил полный цикл:

есть в палитре

создается на форме

выбирается

двигается

меняет размер

редактируется через PropertyPanel

сохраняется в JSON

экспортируется в .py

импортируется обратно

проходит round-trip без потери geometry и свойств



---

2. Зафиксируй модель QDateTimeEdit

Считай QDateTimeEdit обычным leaf-объектом.

Тип

type_name = "QDateTimeEdit"


Роль

editor_kind = "leaf"


Палитра

palette_visible = true

palette_group = "Date and Time"


Поведение

movable = true

resizable = true

deletable_directly = true


Qt-класс

qt_class_name = "QDateTimeEdit"



---

3. Зафиксируй минимальный набор свойств

Подключай только устойчивую базу.

Обязательные свойства

datetime: str

minimum_datetime: str

maximum_datetime: str


Формат хранения

Храни значение только в формате:

YYYY-MM-DD HH:MM:SS


Примеры:

2026-04-08 09:30:00

2025-01-01 00:00:00

2030-12-31 23:59:59



---

Значения по умолчанию

Зафиксируй:

datetime = "2026-01-01 12:00:00"

minimum_datetime = "1900-01-01 00:00:00"

maximum_datetime = "2100-12-31 23:59:59"



---

Что пока не подключай

Не добавляй на этом подэтапе:

display_format

calendar_popup

special_value_text

wrapping

локализацию формата

timezone

отдельное управление секциями даты и времени


Сначала закрой устойчивую базу.

7. Добавь отдельный helper для date-time

Сделай единый набор функций для работы с datetime-строкой.

Например создай:

parse_datetime_string(value: str) -> datetime | None

format_datetime_string(value: datetime) -> str

is_valid_datetime_string(value: str) -> bool

normalize_datetime_string(value: str, fallback: str) -> str



---

Правило

Во всей системе datetime хранится как строка:

YYYY-MM-DD HH:MM:SS


А в Qt преобразуется в:

QDateTime



---

8. Добавь нормализацию свойств QDateTimeEdit

Сделай отдельный helper.

Например:

_normalize_datetime_edit_properties(properties: dict) -> dict


Правило 1

Если datetime отсутствует или невалидно:

ставь дефолтное значение


Правило 2

Если minimum_datetime отсутствует или невалидно:

ставь "1900-01-01 00:00:00"


Правило 3

Если maximum_datetime отсутствует или невалидно:

ставь "2100-12-31 23:59:59"


Правило 4

Если minimum_datetime > maximum_datetime:

при установке minimum_datetime подними maximum_datetime = minimum_datetime

при установке maximum_datetime опусти minimum_datetime = maximum_datetime


Правило 5

Если datetime < minimum_datetime:

ставь datetime = minimum_datetime


Правило 6

Если datetime > maximum_datetime:

ставь datetime = maximum_datetime

9. Добавь QDateTimeEdit в WidgetFactory

В factory/widget_factory.py добавь отдельную ветку.

В create_widget(entity)

Если entity.type == "QDateTimeEdit":

создавай QDateTimeEdit


В apply_properties(widget, entity)

Применяй:

1. setMinimumDateTime(...)


2. setMaximumDateTime(...)


3. setDateTime(...)




---

Порядок применения обязателен

Применяй именно так:

1. minimum


2. maximum


3. current datetime




---

Почему это важно

Сначала фиксируй диапазон, потом текущее значение.
Иначе виджет может скорректировать значение сам.


---

Преобразование строк в QDateTime

Сделай helper:

_to_qdatetime(value: str) -> QDateTime


Используй единый формат:

YYYY-MM-DD HH:MM:SS

12. Нормализуй flow изменений из PropertyPanel

Изменения должны идти только через контроллер.

Для datetime

update_entity_property(entity_id, "datetime", new_value)


Для minimum_datetime

update_entity_property(entity_id, "minimum_datetime", new_value)


Для maximum_datetime

update_entity_property(entity_id, "maximum_datetime", new_value)


После каждого изменения должен проходить единый pipeline:

1. изменение в документе


2. нормализация datetime-свойств


3. flush_json_snapshot()


4. canvas.refresh_view(entity_id)


5. property_panel.rebuild()

14. Проверь serializer

QDateTimeEdit не требует специальных JSON-веток.

Убедись, что в JSON попадают свойства в таком виде:

"properties": {
  "datetime": "2026-04-08 09:30:00",
  "minimum_datetime": "2020-01-01 00:00:00",
  "maximum_datetime": "2030-12-31 23:59:59"
}

Проверь:

значения хранятся именно как строки

формат единый

JSON round-trip не меняет представление

15. Добавь экспорт QDateTimeEdit в PythonExporter

В exporter добавь отдельную ветку для QDateTimeEdit.

Генерируй

1. создание объекта


2. setObjectName(...)


3. setGeometry(...)


4. setMinimumDateTime(QDateTime(...))


5. setMaximumDateTime(QDateTime(...))


6. setDateTime(QDateTime(...))




---

Пример

self.datetime_edit_1 = QDateTimeEdit(self)
self.datetime_edit_1.setObjectName("datetime_edit_1")
self.datetime_edit_1.setGeometry(100, 80, 160, 26)
self.datetime_edit_1.setMinimumDateTime(QDateTime(QDate(2020, 1, 1), QTime(0, 0, 0)))
self.datetime_edit_1.setMaximumDateTime(QDateTime(QDate(2030, 12, 31), QTime(23, 59, 59)))
self.datetime_edit_1.setDateTime(QDateTime(QDate(2026, 4, 8), QTime(9, 30, 0)))


---

Импорты

Если в документе есть QDateTimeEdit, добавляй импорт:

QDateTimeEdit из QtWidgets

QDateTime, QDate, QTime из QtCore

16. Добавь helper генерации QDateTime(...) в exporter
